2. Open Command Prompt/Terminal in this folder.
3. Run a file using: python task1_python_basics.py
4. Repeat for each task.

- Task 2 uses sample values; you can edit them to your own values.
- Task 7 and Task 9 use illustrative sample student information.
- Task 8 creates my_introduction.txt in the current working folder.
- Task 9 stores records in memory while the program is running. Records reset when it exits.
